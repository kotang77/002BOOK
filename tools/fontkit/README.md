# 영원이북 손글씨 글꼴 만들기 (fontkit)

양식(쪽마다 네 모서리 검은 사각형, 17mm 칸 496개)을 손으로 채워 찍은 사진으로 OTF·WOFF2 글꼴을 만든다.

1. `boxes.py` 양식 HTML에서 칸 위치(mm)를 뽑아 `boxes.json` 저장 (양식이 바뀔 때만)
2. `scan.py` 사진 → 모서리 표식으로 펴기 → 쪽 판별 → 칸마다 글자 비트맵
3. `compose.py` 쓴 글자는 그대로, 나머지 KS X 1001 한글 2,350자는 조합
   - 받침 없는 글자: 같은 자음+모음을 쓴 글자 그대로. 없으면 자음(배치별: 기·그·긔에서 분리) + 모음(ㅇ+모음에서 ㅇ을 뺌)
   - 받침 있는 글자: 위 글자를 받침 크기만큼 눌러 담고, 받침(고+받침에서 ㅗ 아래를 잘라 냄)을 아래 가운데에
   - 얘·예: ㅑ·ㅕ + ㅐ·ㅔ의 오른쪽 세로획
   - 낱자 ㄱ~ㅎ, ㅏ~ㅣ도 만듦 (ㅋㅋ, ㅠㅠ)
4. `build.py` 크기 맞추기(받침 없는 글자 높이를 칸의 64%) → potrace 곡선 → OTF(CFF) + WOFF2
5. `run.py` 위를 한 번에 + 미리보기 그림

`simulate.py`는 파이프라인 시험용(공개 글꼴 HiMelody로 양식을 채운 가짜 사진). 시험 결과 글꼴은 배포하지 않는다.
의존: opencv-python, potracer, fonttools, brotli, playwright(+Chrome)
