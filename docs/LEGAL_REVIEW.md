## 3. 이번에 함께 바꾼 것

- **가격**: 1개월 **4,900원**, 6개월 **25,900원** (부가세 포함, 6개월권은 월 약 4,317원으로 약 12% 할인). 결제 화면에 '부가세 포함' 표시. 환불 계산 예시도 이 가격으로 바꿈.
- **회원 정보 공개**: 다른 회원에게는 **닉네임만** 보여요(앱이 주는 그림 캐릭터 포함). 한 줄 소개·학년·거주지역·직접 올린 사진은 회원이 '내 정보 → 공개 설정'에서 켠 것만 보여요. 아이디·이메일·성별·태어난 연월·최근 접속일은 **항상 비공개**예요. 서버가 걸러서 보내기 때문에 화면을 조작해도 볼 수 없어요. 친구 찾기 목록에서도 아이디를 숨겼어요. 기존 회원 3명도 처음에는 모두 비공개예요.

## 4. 남은 위험 (전문가 확인 권장)

1. **보호자 동의 확인 방법**: 시행령 제17조의2제1항이 정한 방법은 7가지예요. 동의 페이지에 표시 + **휴대폰 문자** 알림, 카드, 휴대폰 본인인증, 서면, **이메일 회신**, 전화, 그리고 이에 준하는 방법이에요. 002BOOK은 '동의 페이지 표시 + **이메일** 확인 통지' 방식이라 '준하는 방법'으로 볼 여지가 큰데, 문자 대신 이메일을 쓴다는 점이 해석 문제예요. 가장 확실한 방법은 **휴대폰 본인인증(PASS)을 붙이는 것**이에요. 포트원·다날 등에 건당 수십 원 수준 비용이 들고, 사업자등록 뒤 계약할 수 있어요.
2. **구글 플레이 가족 정책**: 대상 연령에 13세 미만이 포함되면 Families 정책 심사를 받아요. 앱 설명, 데이터 보안 양식, 대상 연령을 서로 맞춰야 해요.
3. **부가가치세**: 온라인 교육 콘텐츠는 보통 과세 대상이라 '부가세 포함' 가격이 맞아요. 다만 간이과세자인지 일반과세자인지에 따라 세금계산서·현금영수증 의무가 달라지니 세무사에게 확인해 주세요.
