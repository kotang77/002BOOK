## 1. 스토어 설명
**간단한 설명 (80자)**
책과 영화로 꿈을 그리고, AI 첨삭으로 논술 실력을 키우는 중학생 인생 서재

**자세한 설명 (4000자 이내)**
002BOOK은 중학생이 매달 책 1권과 영화 2편을 만나며 삶의 의미와 올바른 태도를 배우는 인생교육 서재예요.

📚 학년별 36권 · 108편 코스
중1~중3 학년에 맞춰 책 36권과 영화 108편을 매월 순서대로 추천해요. 책은 저자·가격·출판일, 영화는 볼 수 있는 OTT 정보를 함께 보여 줘요.

🎯 내 취향에 맞춘 맞춤형 코스
난이도, 장르, 분량, 수상작, 좋아하는 책·작가·영화를 고르면 책과 영화를 새로 추천받아요.

✍️ 논술 질문과 AI 첨삭
이달의 책·영화에 맞는 논술 질문 2개를 받고, 노트를 사진으로 올리면 AI가 오탈자·맞춤법·문장·문단 구성까지 꼼꼼히 첨삭해요. 반복되는 실수와 개선점을 누적해서 알려 주고, 모범 답안도 2가지 보여 줘요. 결과는 PDF로 저장하고 인쇄할 수 있어요.

⭐ 함께 읽는 즐거움
인상 깊은 문장과 장면을 기록하고, 별점과 후기를 남겨요. 내 평가를 마친 책·영화는 다른 친구들의 생각도 볼 수 있어요.

## 3. 앱 콘텐츠 설문 (Play Console → 앱 콘텐츠)
- **개인정보처리방침**: 위 URL
- **광고**: 없음
- **앱 액세스 권한**: 로그인 필요 → **심사용 테스트 계정**을 만들어 아이디/비밀번호를 입력해 둔다 (일반 가입 계정 하나를 따로 만들고, 만 14세 이상 생년월로 가입)
- **콘텐츠 등급**: 설문에서 폭력·성적 내용·도박·약물 모두 "없음". 사용자 간 상호작용은 닉네임·후기 공개가 있으므로 "있음"(사용자 생성 콘텐츠)으로 답한다
- **대상 연령**: ⚠ 결정 필요 — 아래 4번 참고
- **데이터 보안 섹션**
  | 수집 데이터 | 수집 | 공유 | 목적 | 선택 여부 |
  |---|---|---|---|---|
  | 이름(닉네임), 이메일, 사용자 ID | 예 | 아니요 | 앱 기능, 계정 관리 | 필수 |
  | 연령(태어난 연월), 성별, 거주지역 | 예 | 아니요 | 앱 기능, 개인 맞춤 | 필수/선택 |
  | 사진(노트·문장·장면) | 예 | 아니요 | 앱 기능 (AI 첨삭) | 선택 |

## 4. 대상 연령 — 결정이 필요한 부분
앱의 주 사용자는 중학생(만 12~15세)이에요. Play는 **만 13세 미만을 대상에 포함하면 '가족 정책'**이 적용돼 요구사항이 늘어요(광고·SDK 제한, 별도 심사 등).
- **안(A)** 대상 연령을 **13~15세, 16~17세, 18세 이상**으로 선택: 절차가 단순해요. 중1 일부(만 12세)는 이론상 대상 밖이에요.
- **안(B)** **만 13세 미만 포함**: 가족 정책 심사를 통과해야 해요. 외부 광고·분석 SDK가 없어 충족하기 쉬운 편이지만 확인 항목이 많아요.
- 앱 자체는 만 14세 미만 가입 시 보호자 동의를 받아요(법정대리인 동의).
권장: 일단 (A)로 출시하고, 중1 사용자가 늘면 (B)로 확대 검토.

## 5. 출시 순서 (개인 개발자 계정)
1. Play Console 개발자 계정 만들기 (등록비 $25, 본인 확인 며칠)
2. 앱 만들기 → 위 3번 설문 작성
3. GitHub Actions **안드로이드 앱 만들기** 실행 → `.aab` 받기
4. **비공개 테스트** 트랙에 .aab 업로드 → 테스터 **12명 이상** 모집(구글 그룹 또는 이메일 목록) → **14일 연속** 옵트인 유지
5. 14일 뒤 **프로덕션 액세스 신청** → 승인 후 프로덕션 출시
6. 앱 서명 키 SHA-256(Play Console → 앱 무결성)을 `ANDROID_SHA256` 변수에 넣고 웹 재배포 → 주소창 없는 진짜 앱 화면
(사업자 계정은 4번의 12명·14일 조건이 없어요.)
