## 1. 서버 (Supabase) — 약 20분
1. supabase.com 가입 → New project → 이름 `002book`, **Region: Northeast Asia (Seoul)**, DB 비밀번호 저장
2. Settings → API 에서 **Project URL**, **anon public key**, Project ref 확인
3. 운영은 **Pro 요금제($25/월) 권장**: 무료 요금제는 1주일간 접속이 없으면 일시정지돼요
4. Database → Extensions 에서 `pg_cron` 켜기 (매일 정리 작업)

## 6. 구글 플레이 앱
1. GitHub Secrets에 `ANDROID_KEYSTORE_PASSWORD`(8자 이상, 따로 보관) 추가
2. Actions → '안드로이드 앱 만들기' 실행 → 처음엔 서명 키가 새로 만들어져 결과물로 나와요
   → **반드시 두 곳 이상에 백업** (잃으면 앱 업데이트 불가) → base64로 바꿔 `ANDROID_KEYSTORE_B64` Secret에 저장
3. 실행 요약에 나온 SHA-256 지문 + Play Console의 **앱 서명 키 지문**(설정 → 앱 무결성)을 쉼표로 이어 `ANDROID_SHA256` Variable에 넣고 웹 배포를 다시 실행 → 앱 위쪽 주소창이 사라져 진짜 앱처럼 보여요
4. Play Console: 앱 만들기 → `app-release-bundle.aab` 업로드
   - **대상 연령**: 13세 미만이 포함되면 '가족 정책(Families)' 심사를 받아요. 중학생 대상이면 13~15세를 고르되 앱 설명을 일관되게.
   - **데이터 보안 양식**: 개인정보처리방침(https://002book.com/privacy.html) 기준으로 작성 (계정 정보, 사용자 콘텐츠, 사진 수집 / 전송 시 암호화 / 삭제 요청 가능)
   - 앱 안에서는 결제 버튼을 숨겼어요 (구글 정책상 디지털 상품은 플레이 결제를 써야 해서). 결제는 웹사이트에서만.
   - 스토어 그래픽: `dist/icons/icon-512.png`, `dist/icons/play-feature.png`(1024×500) 사용, 스크린샷은 휴대폰에서 캡처

## 바뀐 점 (Claude 게시본 대비)
- 로그인·비밀번호·권한을 서버가 판단 → 다른 회원의 이메일·비밀번호 해시·진도·첨삭·일기가 보이지 않음
- 비밀번호 8자 이상, 비밀번호 찾기는 관리자 확인 없이 **임시 비밀번호가 자동으로 메일 발송**
- 회원가입에 태어난 연월, 만 14세 미만 보호자 동의(동의 페이지 + 확인 메일), 약관 동의, 생성형 AI 고지 추가
- 다른 회원에게는 닉네임만 공개, 나머지는 '공개 설정'에서 켠 항목만
- 유료회원 신청 → 토스 결제 즉시 전환 (자동 갱신 없음, 기간 끝나면 자동으로 무료회원)
- 휴대폰 '홈 화면에 추가'로 앱처럼 설치(PWA), 오프라인 안내 화면
- AI 호출은 서버에서만 (API 키가 화면에 노출되지 않음), 회원별 하루 한도

## 무료 출시 → 유료 전환 (사업자등록 전 단계)
현재는 **무료 출시 모드**(`site.config.json`의 `freeLaunch: true`, 서버 `FREE_LAUNCH=1`)다.
- 결제 화면(`/pay/*`)은 빌드에서 빠지고, 서버의 `pay.*` 요청은 막혀 있다. 모든 회원이 맞춤형코스를 쓸 수 있다.
- 약관 제10·11조, 개인정보 처리방침(결제 항목·토스 위탁), 환불정책은 "현재 무료" 문구로 바뀐다.
- 사업자 정보 칸에는 "TAi Edutech (개인 운영 · 사업자 등록 전)"과 문의 이메일만 표시된다. 사업자등록 뒤 business.name(상호)을 채우면 전자상거래법 표시 항목으로 바뀐다.

**유료로 바꿀 때 순서**
1. 개인사업자(간이과세) 등록 → 통신판매업 신고 → 토스페이먼츠 가맹 승인
2. `site.config.json`: `freeLaunch: false`, `business.*`, `tossClientKey` 채우기
3. GitHub Variables에 `FREE_LAUNCH=0` 추가, Secrets에 `TOSS_SECRET_KEY` 등록
4. 약관·방침 개정 공지(시작 30일 전) 후 배포
