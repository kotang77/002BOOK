## 1. 서버 (Supabase) — 약 20분
1. supabase.com 가입 → New project → 이름 `002book`, **Region: Northeast Asia (Seoul)**, DB 비밀번호 저장
2. Settings → API 에서 **Project URL**, **anon public key**, Project ref 확인
3. 운영은 **Pro 요금제($25/월) 권장**: 무료 요금제는 1주일간 접속이 없으면 일시정지돼요
4. Database → Extensions 에서 `pg_cron` 켜기 (매일 정리 작업)

## 2. 비밀 키 3개 발급
| 키 | 어디서 | 비고 |
|---|---|---|
| ANTHROPIC_API_KEY | console.anthropic.com → API Keys | 사용량만큼 과금. 회원당 하루 AI 호출 한도: 무료 30회 / 유료 200회 (변경 가능) |
| RESEND_API_KEY | resend.com → 도메인 002book.com 추가 → 안내되는 DNS(TXT/MX) 등록 | 임시 비밀번호·보호자 동의 메일. 월 3,000통 무료 |
| TOSS_SECRET_KEY | 토스페이먼츠 개발자센터 | 심사 전에는 **테스트 키**로 먼저 연결해 결제 흐름 확인 가능 |

## 3. GitHub — 약 15분
1. 저장소 `kotang77/002book` 만들기 → 받은 zip의 내용을 올리기 (또는 claude.ai 설정 → 커넥터에서 GitHub 연결 후 Claude에게 "올려줘")
2. Settings → Secrets and variables → Actions
   - **Variables**: `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_PROJECT_REF`
   - **Secrets**: `SUPABASE_ACCESS_TOKEN`(supabase.com → Account → Access Tokens), `SUPABASE_DB_PASSWORD`, `ANTHROPIC_API_KEY`, `RESEND_API_KEY`, `TOSS_SECRET_KEY`
3. Settings → Pages → Source: **GitHub Actions**
4. Actions 탭 → '배포 (웹사이트 + 서버)' 실행 → 서버 DB·API와 웹사이트가 한 번에 배포돼요
5. `site.config.json`에 사업자 정보(상호·대표·사업자번호·통신판매업 번호·주소·연락처)와 토스 **클라이언트 키** 입력 → 모든 페이지 하단과 약관에 자동 반영

## 4. 도메인 002book.com 연결 (구입한 곳의 DNS 설정)
| 종류 | 이름 | 값 |

| A | @ | 185.199.108.153 / 185.199.109.153 / 185.199.110.153 / 185.199.111.153 (4개) |

GitHub → Settings → Pages → Custom domain에 `002book.com` 저장 → 몇 분~몇 시간 뒤 **Enforce HTTPS** 체크.

## 5. 기존 데이터 옮기기 — 5분
1. https://002book.com/admin/import.html 열기
2. 받아 둔 `002book-export.json` 선택 + kotang77의 **지금 비밀번호** 입력 → 가져오기
3. 따님·가족은 원래 아이디·비밀번호 그대로 로그인 (첫 로그인 때 비밀번호 저장 방식이 자동으로 더 안전하게 바뀜)
4. 일기 잠금도 그대로 열려요. 단, **4자리 등 8자 미만 비밀번호**는 로그인은 되지만 다음 비밀번호 변경 때 8자 이상으로 바꿔야 해요.

## 6. 구글 플레이 앱
1. GitHub Secrets에 `ANDROID_KEYSTORE_PASSWORD`(8자 이상, 따로 보관) 추가
2. Actions → '안드로이드 앱 만들기' 실행 → 처음엔 서명 키가 새로 만들어져 결과물로 나와요
   → **반드시 두 곳 이상에 백업** (잃으면 앱 업데이트 불가) → base64로 바꿔 `ANDROID_KEYSTORE_B64` Secret에 저장
3. 실행 요약에 나온 SHA-256 지문 + Play Console의 **앱 서명 키 지문**(설정 → 앱 무결성)을 쉼표로 이어 `ANDROID_SHA256` Variable에 넣고 웹 배포를 다시 실행 → 앱 위쪽 주소창이 사라져 진짜 앱처럼 보여요
4. Play Console: 앱 만들기 → `app-release-bundle.aab` 업로드
   - **대상 연령**: 13세 미만이 포함되면 '가족 정책(Families)' 심사를 받아요. 중학생 대상이면 13~15세를 고르되 앱 설명을 일관되게.
   - **데이터 보안 양식**: 개인정보처리방침(https://002book.com/privacy.html) 기준으로 작성 (계정 정보, 사용자 콘텐츠, 사진 수집 / 전송 시 암호화 / 삭제 요청 가능)
   - 앱 안에서는 결제 버튼을 숨겼어요 (구글 정책상 디지털 상품은 플레이 결제를 써야 해서). 결제는 웹사이트에서만.
   - 스토어 그래픽: `dist/icons/icon-512.png`, `dist/icons/play-feature.png`(1024×500) 사용, 스크린샷은 휴대폰에서 캡처

## 바뀐 점 (Claude 게시본 대비)
- 로그인·비밀번호·권한을 서버가 판단 → 다른 회원의 이메일·비밀번호 해시·진도·첨삭·일기가 보이지 않음
- 비밀번호 8자 이상, 비밀번호 찾기는 관리자 확인 없이 **임시 비밀번호가 자동으로 메일 발송**
- 회원가입에 태어난 연월, 만 14세 미만 보호자 동의, 약관 동의 추가
- 유료회원 신청 → 토스 결제 즉시 전환 (자동 갱신 없음, 기간 끝나면 자동으로 무료회원)
- 휴대폰 '홈 화면에 추가'로 앱처럼 설치(PWA), 오프라인 안내 화면
- AI 호출은 서버에서만 (API 키가 화면에 노출되지 않음), 회원별 하루 한도
